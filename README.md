# موجه

مدير راوتر شخصي. حمّل ملف التثبيت من صفحة الإصدارات.

**الإصدار 1.0.0** — رمز الإصدار 1 — الحزمة `app.muwajjih`

[تحميل Muwajjih-1.0.0.apk](https://github.com/aalbahrii999/muwajjih-apk/releases/download/v1.0.0/Muwajjih-1.0.0.apk)

## التثبيت

1. حمّل الملف على الجوال.
2. اسمح بالتثبيت من مصادر غير معروفة.
3. افتح الملف وثبّته.

## الاستخدام

- الوضع التجريبي يعمل بدون راوتر.
- وضع هواوي يعمل والجوال على شبكة الراوتر نفسها. العنوان الافتراضي `http://192.168.8.1`.
- كلمة مرور الراوتر لا تُحفظ في التطبيق.

## حدود هذا الإصدار

- لا توليد IMEI ولا فتح قفل الشريحة.
- التوقيع الحالي توقيع تصحيح. إذا تغيّر مفتاح التوقيع لاحقاً قد تحتاج حذف التطبيق ثم إعادة التثبيت.

المصدر داخل هذا المستودع. البناء يحتاج Android SDK 35 و Gradle 8.10.
